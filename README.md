# NovoCommunicate – Klickdummy

Prototyp der Kampagnen-Plattform NovoCommunicate: Ein Claude-Agent holt sich über MCP Kampagnenaufgaben, kommuniziert über E-Mail, WhatsApp, LinkedIn, Instagram, YouTube-Kommentare und App-Push und meldet Ergebnisse zurück.

**Live:** https://novogenia-ag.github.io/novocommunicate-klickdummy/

Alle Kontakte, Adressen und Zahlen sind Demo-Daten. Kein Backend – reines HTML.
